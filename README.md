**[Realwise](https://realtor-os-hazel.vercel.app/home)** · Next.js, Supabase, AWS (S3, Textract, Bedrock), DocuSeal · *pre-launch*

An AI transaction copilot for Texas realtors, built with a licensed industry partner. It tracks a deal from listing or offer to closing, computes every contract deadline, fills state forms, and explains documents to clients in Korean. Analysis runs on Claude through AWS Bedrock, and nothing is sent without the agent's click. *(Code is private.)*
